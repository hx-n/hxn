Run the examples

For the API tutorials, use the current examples and CLI from the same checkout. Install Rust, Haxe and a runtime first; hxn doctor checks the tools.

Prepare the examples
git clone https://github.com/hx-n/hxn.git
cd hxn
cargo install --path crates/hxn-cli
hxn doctor

Each API tutorial shows excerpts from an existing program and links to its complete source. Run commands start at the repository root.
