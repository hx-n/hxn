Plugin

Plugin is the main function of a tool that a haxelib registers with hxn, as hxn.cli in its haxelib.json describes. hxn sends the tool one request on standard input. For a command, such as hxn me dev, Plugin runs the command that the arguments select. For a hook, it calls hook and prints its reply:

static function main()
    hxn.cli.Plugin.main(new hxn.cli.Cli("hxn me", "Creates and develops hxnme apps.", [new New(), new Dev()]), hook);

A Failure that a command or hook throws prints its message after the tool's name, on standard error, and ends the process with its status. Any other exception ends it with status 1.
