Callback

Support for a binding that passes a Haxe function to native code as a callback.

An exception cannot unwind through native code, so a binding wraps the function it passes. The wrapper catches the exception, passes it to failed, and returns the value that reports a failed callback to the library. The library stops and returns. The binding makes the native call inside during, which then rethrows the original exception to the caller.

Static methods

function failed(error:Exception):Void

Records the exception a callback threw. Only the first one in a native call is reported.

function during(call:() -> T):T

Runs call, a native call that was passed callbacks, and returns its result. If a callback threw, its exception is rethrown here and replaces the result or error the library returned.
