Cli

ConstructorStatic methodsPropertiesMethods

Cli runs one of a tool's commands with the arguments that the user gave. It picks the command by the first argument, gives the command's fields their values from the rest, and calls its run. --help or -h prints the help of the tool or of a command. A mistake in the arguments prints the mistake and the command's usage to standard error, and ends with status 2.

Options take their value as the next argument or after =, as in --ash ash or --ash=ash, and can come before, between or after the positional arguments. -- ends the options: the arguments after it are positional.
