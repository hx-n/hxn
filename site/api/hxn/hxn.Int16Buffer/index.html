Int16Buffer

  • Over Bytes

A fixed number of signed 16-bit integers in one block of memory.

A library function that takes &[i16] reads the buffer for the duration of the call, and a function that takes &mut [i16] writes it. When the memory is aligned for i16, nothing is copied. The library cannot keep the buffer after the call returns.

The length does not change. resized returns a new buffer and does not change this one.

When you set a value, the buffer keeps only its low 16 bits.

Indexing checks bounds only when you compile with -debug.
