AtomicInt

ConstructorStatic methodsProperties

An integer shared by a native library and Haxe. Either side reads and writes it from any thread without a native call.

The cell is four bytes of memory that both this runtime's atomic operations and the library's operate on. A cell created here with new can be passed to a native call, which borrows it for the duration of the call. A cell returned by a library is in the library's memory and is read and written from Haxe directly. The operations are those of haxe.atomic.AtomicInt.
