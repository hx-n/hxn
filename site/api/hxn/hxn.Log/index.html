Log

Static fieldsStatic methods

Shared logging for Haxe and Rust libraries. Set level and sink on the app thread. By default Rust records are pulled after native calls and during Loop.sync; flush explicitly when an otherwise idle native worker can produce logs. No worker calls a Haxe sink. Logging does not keep an idle app alive.
