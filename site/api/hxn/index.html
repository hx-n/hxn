API / hxn 0.3.7

hxn

Futures, streams, signals, reactive values, atomics and callbacks: the Haxe classes every hxn library uses.

haxelib install hxn 0.3.7Source ↗haxelib ↗

Classes

  • AtomicBoolA boolean flag shared by a native library and Haxe.
  • AtomicIntAn integer shared by a native library and Haxe.
  • CallbackSupport for a binding that passes a Haxe function to native code as a callback.
  • ComputedA value derived from signals and other computed values, and cached until one of them changes.
  • FutureThe single result or failure of an asynchronous operation.
  • GcGarbage collection control for native memory, which the collector cannot measure.
  • InboxDelivers one native library's results to the app.
  • LoopControls when results from native libraries are delivered to the app.
  • MeterTracks the memory one library's values hold, which the collector cannot measure, and decides when to run a collection for it.
  • ReactiveFine-grained reactivity in the style of SolidJS: Signal holds a value, Computed derives one, and an effect is code that reruns when a value it read changes.
  • SignalA mutable value that tracks its readers.
  • StreamA sequence of results from a native library, such as events.
  • TupleA fixed group of typed values, such as Tuple<String, Int>.

Enums

  • UnitThe value type of a future or stream that has no data to return.

Abstracts

  • SetA mutable set of values exchanged with Rust.
