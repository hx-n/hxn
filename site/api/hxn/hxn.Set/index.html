Set

  • Type parameters: T
  • Over SetValues<T>

A mutable set of values exchanged with Rust.

Array literals are accepted as sets. Construction copies the elements; toArray also returns a copy. Iteration preserves insertion order, or the order received from Rust. Adding an element does not sort the set.

Membership uses Haxe == by default, including identity for objects. Pass an equality function when values need a different comparison. Rust applies its own Eq or Ord when it receives the set.
