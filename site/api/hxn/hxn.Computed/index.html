Computed

  • Type parameters: T
ConstructorProperties

A value derived from signals and other computed values, and cached until one of them changes. SolidJS calls this a memo.

It is computed on first read. It is recomputed only when a dependency has changed and either it is read again or an effect depends on it. If the new value equals the old one, its dependents do not rerun.
