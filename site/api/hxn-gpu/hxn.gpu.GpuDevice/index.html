GpuDevice

Static methodsPropertiesMethods

A GPU device on one backend, opened with GpuDevice.open. It creates resources and pipelines and runs submitted commands in order. Buffer and texture reads and writes are ordered with submissions: a write is visible to work submitted after it, and a read sees the results of work submitted before it.

features and limits say what the device can do. A call that lacks a feature throws and names the feature and the backend.

Add a driver haxelib for each backend to support, such as -lib hxn-gpu-metal -lib hxn-gpu-vulkan. Only those backends are compiled in, and open uses the first one that initializes.

Static methods

function backends():Array<Backend>

The compiled-in backends.

function defaultBackends():Array<Backend>

The compiled-in backends in the order open tries them by default. Apple platforms prefer Metal, Windows prefers Direct3D 12, other native platforms prefer Vulkan, and each falls back to Vulkan and then GLES. The browser prefers WebGPU and falls back to WebGL2.

HXN_GPU_BACKEND at run time, or -D hxn_gpu_backend at compile time, replaces this order with a comma-separated list such as vulkan,gles. The environment variable wins when both are set.

function featuresOf(backend:Backend):Features

The features of backend's devices, without opening one.

function open(?options:Null<OpenOptions>):Future<GpuDevice>

Opens a device on the first backend that has the options.required features and initializes, trying options.backends or, by default, defaultBackends() in order. If none does, the future fails with the reason for each backend.
