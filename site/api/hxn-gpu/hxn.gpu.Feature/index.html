Feature

  • Over Int
ValuesFields and methods

A capability that only some backends support. GpuDevice.features lists the features a device has, and GpuDevice.open skips backends that lack the ones in required. A call that lacks a feature throws and names the feature and the backend.

Values

  • Compute = 1

    Compute pipelines and passes. Not on GLES or WebGL2.

  • StorageTextures = 2

    Textures that shaders write, created with TextureUsage.Storage.

  • TextureWrites = 4

    Writing texture contents from the CPU with GpuDevice.writeTexture.

  • IndexedDraws = 8

    RenderPass.setIndexBuffer and drawIndexed.

  • BindingOffsets = 16

    Binding part of a buffer in a bind group: a non-zero offset, or a size smaller than the rest of the buffer.

  • MultipleVertexBuffers = 32

    A render pipeline reading vertices from more than one buffer.

  • BufferCopies = 64

    CommandEncoder.copyBufferToBuffer.

  • InstanceVertexBuffers = 256

    Vertex buffers that step once per instance, set with VertexBufferLayout.perInstance.

  • PipelineConstants = 128

    Setting a shader's @const values when a pipeline is created. Without it, they are fixed at compile time.

  • Presentation = 512

    Presenting to a window or the web page's canvas through a GpuSurface.

Fields and methods
