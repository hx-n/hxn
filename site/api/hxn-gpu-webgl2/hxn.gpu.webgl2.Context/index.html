function claimCanvas():Future<Unit>

Takes the web page's canvas, which present shows the drawing buffer on. With threads the context draws on a canvas of its own, and fails here when the page has no canvas or another browser agent holds it; without, it settles at once.

function present():Void

Shows what was drawn into the default framebuffer on the web page's canvas. Without threads the browser shows it once the program returns to its event loop.
