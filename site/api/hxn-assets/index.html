API / hxn-assets 0.1.0

hxn-assets

Typed annotated assets, asynchronous loading, remote streams, content identity and opt-in knowledge metadata with relationships and spatial bounds.

haxelib install hxn-assets 0.1.0Source ↗haxelib ↗

Classes

  • AssetCatalogAn immutable, validated snapshot of addresses, labels, groups and dependencies.
  • AssetLoaderAsynchronous dependency loading with a bounded byte cache on the Haxe event thread.
  • AssetsGenerates typed asset values, catalogs and provider addresses from metadata.
  • AssetStreamA pull stream of decoded messages or chunks, with one pending read at a time.
  • BuildCatalog/staging implementation shared by compiler integration and the installed CLI.
  • FileSourceBorrows a Storage and reads from its read-only bundled asset root.
  • ImageDataCPU image pixels: unpremultiplied RGBA8, rows top first, tightly packed.
  • KnowledgeTyped knowledge capture and explicit bounded publication on the Haxe event thread.
  • KnowledgeBatchAn immutable, bounded, coalesced update from one scoped source revision.
  • KnowledgeSnapshotOwned selected data captured by Knowledge.capture, independent of later edits.
  • MemoryKnowledgeSinkPortable reference sink and relationship/AABB queries; no spatial index is implied.
  • RemoteSourceHTTP(S) values and streams, and WS(S) message streams; optional borrowed fallback for local keys.
  • StaticCatalog

Interfaces

  • AssetSourceReads a source key asynchronously.
  • AssetStreamDriverPull transport for byte chunks or complete messages; it owns its connection.
  • CatalogSourceProduces an immutable catalog snapshot without selecting a hosting provider.
  • KnowledgeSinkAtomically applies one source revision.
  • StreamingAssetSourceA source that can also open bounded pull streams.

Abstracts

  • KnowledgeRefA stable semantic ID whose target schema is checked by the knowledge macro.

Typedefs

  • AssetInfoA logical address and its source key, with optional verified content identity.
  • KnowledgeAssetOriginSource identity only; transport URIs, headers and credentials are excluded.
  • KnowledgeBatchData
  • KnowledgeBoundsWorld-coordinate AABB; point declarations have equal minimum and maximum.
  • KnowledgeDataVersioned wire data selected by knowledge metadata, without live object pointers.
  • KnowledgeFactA scalar or homogeneous scalar-array property.
  • KnowledgeRelationA named, typed outgoing relationship selected from a declaration field.
  • KnowledgeSchemaThe selected semantic fields of one annotated Haxe type.
  • KnowledgeSpatialSelectionThe relationship supplying the coordinate space and its declared unit system.
  • RemoteOptionsBounded native/page transport settings; credentials are supplied by the application at runtime.
  • StreamItemA stream boundary separate from a nullable payload and an empty message.
