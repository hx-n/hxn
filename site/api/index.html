API

API reference

The Haxe API of every hxn library at its released version: hxn, hxn-window, hxn-av, hxn-audio, hxnsl, hxn-gpu and the hxn GPU drivers.

0.3.9 / 18 types

hxn →

Shared logging, futures, streams, signals, reactive values, atomics and callbacks: the Haxe classes every hxn library uses.

0.2.2 / 42 types

hxn-window →

Native and browser windows, input, monitors, gamepads and the clipboard, with handles for GPU surfaces.

0.2.1 / 40 types

hxn-av →

Audio and video with the platform's codecs: playback, frames, PCM audio, an equalizer, AAC, H.264 and MP4.

0.1.2 / 19 types

hxn-audio →

Audio output and mixing: voices, bounded PCM streams, buses and effects on native and browser runtimes. The Av and DecoderStream helpers require hxn-av.

0.2.1 / 8 types

hxnsl →

Shaders written in HXSL and translated at compile time to WGSL, MSL, HLSL, SPIR-V and GLSL ES.

0.2.4 / 46 types

hxn-gpu →

One GPU API over every hxn GPU driver, with features and limits per device and a default backend per platform.

0.2.1 / 27 types

hxn-gpu-metal →

Metal on macOS and iOS: compute and render passes, with hxnsl shaders compiled into Metal libraries.

0.3.1 / 32 types

hxn-gpu-vulkan →

Vulkan on Linux, Windows, Android and macOS: compute, rendering, explicit barriers and swapchains.

0.2.1 / 28 types

hxn-gpu-d3d12 →

Direct3D 12 on Windows: compute, rendering, textures and swapchains, with transitions or enhanced barriers.

0.3.1 / 17 types

hxn-gpu-gles →

OpenGL ES 3.0 over EGL on Android, Linux, macOS and Windows: rendering, textures and windows.

0.3.4 / 34 types

hxn-gpu-webgpu →

WebGPU in the browser, on hxcpp and Ash compiled to wasm: compute, rendering and the web page's canvas.

0.3.3 / 16 types

hxn-gpu-webgl2 →

WebGL2 in the browser, on hxcpp and Ash compiled to wasm, for browsers without WebGPU.
