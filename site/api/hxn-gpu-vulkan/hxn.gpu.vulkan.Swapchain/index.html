function acquire():Image

Waits for the window system's next image, and returns it to render into. It stays this swapchain's: present shows it, and closing the returned image frees only its view.

function present():Bool

Shows the image acquire gave, once the work submitted before has finished; it must be in Layout.Present. Returns false when the window changed and the swapchain needs resize.

function resize(width:Int, height:Int):Void

Makes the swapchain again for the window's new size.

function close():Void

Releases the native value now. The collector does it otherwise. Using this object afterwards throws.
