hxn-gpu-vulkan

Vulkan on Linux, Windows, Android and macOS: compute, rendering, explicit barriers and swapchains.

Classes

  • BufferMemory the CPU maps for as long as the buffer lives.
  • CommandBufferRecords commands until a Device.submit.
  • DescriptorSetA descriptor set, written binding by binding before a command buffer binds it.
  • DeviceA logical device and its queue; every other object comes from one.
  • ImageA 2D image in device memory, with one view of all of it.
  • ImageDescriptor
  • InstanceA Vulkan instance: the loader, and the GPUs it finds.
  • LayoutBindingOne binding of a descriptor set layout.
  • Pipeline
  • PipelineLayout
  • Sampler
  • SetLayoutOne descriptor set's bindings: one of hxnsl's bind groups.
  • SetLayoutsThe descriptor set layouts of a pipeline, set 0 first.
  • ShaderModule
  • ShadersShaders from hxnsl, for Vulkan.
  • SurfaceA window's Vulkan surface, which a swapchain presents to.
  • SwapchainA window's images to render into and present, made for one size.
  • VertexAttributeOne vertex attribute: location is the shader's (hxnsl's INPUT_<name>).
  • VertexBindingOne vertex buffer binding: its stride in bytes, and whether it advances per instance.
