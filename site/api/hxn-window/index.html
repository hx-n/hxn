API / hxn-window 0.2.1

hxn-window

Native and browser windows, input, monitors, gamepads and the clipboard, with handles for GPU surfaces.

haxelib install hxn-window 0.2.1Source ↗haxelib ↗

Classes

  • ClipboardItemsRepresentations of one thing, by MIME type, which write puts on the clipboard together so that a reader takes the richest it understands: text/plain beside text/html, or image/png beside text/plain.
  • GamepadA connection-scoped controller handle; reconnecting invalidates the old handle.
  • MonitorA display.
  • VideoModeA size, depth and refresh rate a monitor can run at, for exclusive fullscreen.
  • Window
  • WindowAttributesWhat a window opens with; whatever is left unset is the platform's default.
