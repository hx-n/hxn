Drain whole 32-byte records into reused storage without constructing event objects. u32 kind, i32 device, u32 control, u32 pressed, f64 value, u64 dropped. Kinds match GamepadEvent variants. Returns count; a short buffer consumes nothing.

Atomically copy into a reused 176-byte buffer: 17 little-endian f64 button values, 4 f64 axes, a u32 pressed mask and a u32 change sequence. False for an invalid handle or short buffer; no bytes are written then.
